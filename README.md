# Персональный сайт — Иван Галь

Кинематографичный сайт-портфолио (HTML/CSS/JS + GSAP), публикуется через GitHub Pages из папки `docs/`.

- Язык выбирается по региону: часовой пояс СНГ → русский, Европа/Америка → английский, остальные → по языку браузера. Ручной переключатель RU/EN запоминается.
- Разделы: Главная/Обо мне · Резюме и портфолио · Бизнес-идея · Блог · Контакты.
- Личные ссылки — в `docs/config.js`, фото — `docs/assets/photo.jpg`.

## Публикация (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → ветка с сайтом, папка `/docs` → Save.
Через 1–2 минуты сайт откроется по адресу `https://<username>.github.io/<repo>/`.

## Локальный просмотр
```bash
cd docs && python3 -m http.server 8000
```
